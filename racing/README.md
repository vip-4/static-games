# Racing Games Collection

## Available Games

### 1. Retro Racer
- Type: Top-down racing
- Difficulty: Easy
- Controls: Arrow keys / WASD
- Features: 3 cars, 4 tracks, split-screen

### 2. Pixel Rally
- Type: Rally racing
- Difficulty: Medium
- Controls: Arrow keys
- Features: Day/night, weather effects, damage system

### 3. Formula 8-bit
- Type: Formula racing
- Difficulty: Hard
- Controls: Arrow keys, Space for boost
- Features: 8 cars, 6 tracks, nitro boost

## Tech Stack
- HTML5 Canvas 2D
- Vanilla JavaScript
- Procedural track generation
- Sprite-based car rendering
