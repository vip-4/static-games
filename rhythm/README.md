# Rhythm Games Collection

## Available Games

### 1. Beat Tap
- Type: Rhythm tapping
- Difficulty: Easy
- Controls: Mouse / Touch
- Features: 3 songs, 3 difficulty levels, combo system

### 2. Piano Tiles
- Type: Piano tiles
- Difficulty: Medium
- Controls: Mouse / Keyboard (A-S-D-F)
- Features: 5 songs, falling notes, accuracy scoring

### 3. Drum Hero
- Type: Drum simulation
- Difficulty: Hard
- Controls: Keyboard (A-S-D-F-J-K)
- Features: 4 instrument tracks, real drum samples, combo multiplier

## Tech Stack
- HTML5 Canvas
- Web Audio API
- RequestAnimationFrame timing
- Procedural note generation
